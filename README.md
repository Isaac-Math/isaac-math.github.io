# isaac-math.github.io

`faithreason.kr` 루트 도메인 레포 (GitHub Pages 사용자 사이트). 콘텐츠는 각 시리즈 레포에 있고, 이 레포는 도메인 전체가 공유하는 파일만 둔다.

| 파일 | 역할 | 비고 |
|---|---|---|
| `CNAME` | 커스텀 도메인 `faithreason.kr` | **삭제 금지** |
| `index.html` | 루트 → `/Faith_Reason/` 포털로 이동(meta refresh + canonical) | |
| `404.html` | 도메인 공통 404 페이지 | 각 시리즈 레포에도 같은 파일이 있음 |
| `sitemap.xml` | 전 시리즈 30 URL | Search Console·네이버에 제출됨 — 페이지 추가·수정 시 갱신 |
| `robots.txt` | 전체 허용 + sitemap 위치 | **삭제 금지** |
| `naver*.html` | 네이버 서치어드바이저 소유 확인 | **삭제 금지** |
| `favicon.svg` · `favicon.ico` · `apple-touch-icon.png` | FR 모노그램 파비콘(2026-09-25) — 전 페이지가 절대 URL로 참조 | SVG가 원본 |
| `og-image.png` | 공유 미리보기 이미지 1200×630 | 전 페이지 `og:image` |
